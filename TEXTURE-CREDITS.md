# Texture sources

Wood fine-grain normal and roughness: Wood Table 001, Poly Haven, by Dimitrios Savva (photography) and Rico Cilliers (processing). CC0. https://polyhaven.com/a/wood_table_001

Downloaded official 1K JPEG normal (OpenGL) and roughness maps; verified MD5 against official API metadata. Applied to four WEB wood materials at reduced normal strength; existing approved base colours retained. Divider material unchanged. Other textures derive from existing apartment source materials.

Woven fabric normal and roughness: Fabric Pattern 07, Poly Haven, Rob Tuytel, CC0. https://polyhaven.com/a/fabric_pattern_07 . Official 1K JPEG files verified against API MD5 metadata; olive colour retained through locally generated cloth-nap variation.

Wood colour detail also uses the verified official Wood Table 001 diffuse map. Local colour-preserving variants retain the approved medium oak and darker kitchen finishes; repeated variants are shared and JPEG-compressed.
